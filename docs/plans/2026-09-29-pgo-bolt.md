- Scope: extend the existing GNU/Linux host build with comprehensive live training, fresh compiler-matched PGO profiles, BOLT instrumentation/layout optimization, artifact identity checks and repeated measurements. Every optimized training stage passed the same complete coverage, including BOLT instrumentation and the final stripped binary. - Measurements: native `oha` remeasurement used pooled HTTPS, four assigned server cores, disjoint client cores, concurrency sweeps, client-thread headroom checks and three rotated rounds with 15 samples per variant/workload. Baseline/PGO/PGO+BOLT reached 272,837/308,685/306,277 small-health requests/s and 44,874/52,925/53,889 mixed requests/s with zero failures across 27 million primary requests. PGO improved mixed throughput by 17.9%; BOLT by 20.1% against baseline. The original Playwright reports retain their historical failed gate but cannot establish backend regressions because the client searched growing test history on each API call. Native mixed comparisons meet all original budgets; small-health p99 comparisons exceed the 5% latency budget. See the [results, headroom evidence and artifact identities](2026-09-30-pgo-bolt-results.md).
