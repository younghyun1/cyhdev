- Status: completed September 30, 2026. Optimized baseline, PGO and PGO+BOLT binaries were produced and benchmarked. The primary campaign failed its performance acceptance gate; all binaries and evidence remain available.
- Scope: extend the existing GNU/Linux host build with comprehensive live training, fresh compiler-matched PGO profiles, BOLT instrumentation/layout optimization, artifact identity checks and repeated measurements. The explicit optimized-build request authorized this campaign despite the ordinary development-build restriction.
- Checkout: `main`; implementation commits include `d5dd3d5` (optimization pipeline), `20f06de` (disposable fixtures and complete workloads), `32c4090` (dependency-source permissions), and `1e88078` (native worker profile paths and canonical Debian BOLT runtime lookup). - Implementation: `cargo xtask optimize inventory|plan|run` owns the isolated builder, exact profile merge tools, source/configuration/campaign/binary checks, complete coverage gates, repeated comparisons, ELF validation and conditional export. `optimization-fixtures` supplies bounded synthetic PostgreSQL, SMTP, S3, OIDC, Minecraft and management dependencies. Backend/browser/protocol workflows exercise successful and denied authority, real mail capabilities, content/moderation, media processing, background jobs, WebSockets, RTC media, Minecraft visibility/tiles and embedded EU5/WASM.
- Verification: development coverage passed 112 HTTP operations, 33 routes across 264 viewport/theme/locale states, and 31 scenarios. Every optimized training stage passed the same complete coverage, including BOLT instrumentation and the final stripped binary. Native/WASM clippy, format and OpenAPI checks passed; fixture/workload implementation passed 447 unit tests, 304 frontend application tests and 10 driver tests. Subsequent profile/runtime corrections passed all 61 xtask tests and clippy, including a native Cargo probe with a space-bearing path and an environment-cleared child. BOLT startup, graceful profile flush, merge, layout, stripping and PIE/provenance probes passed.
- Measurements: nine 3,000-request samples per variant at concurrency eight, plus rotated repeats totaling 15 samples per variant. Primary PGO p99 regressed 7.3%, exceeding the unchanged 5% gate. Shorter rotated passes put PGO throughput within 0.1% of baseline and PGO+BOLT about 1% ahead; the tail regression did not reproduce. These client-inclusive loopback measurements establish no meaningful capacity gain. See the [results and artifact identities](2026-09-30-pgo-bolt-results.md).
- Handoff: requested build/benchmark work is complete. The primary failed receipt was preserved, diagnostic repeats did not replace it, and no accepted `dist/` export was produced. Owned fixture processes were stopped after measurements. Production services, installation, deployment, publication and real user data stayed outside scope.
