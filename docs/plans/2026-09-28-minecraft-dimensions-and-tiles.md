Transport: binary with gzip is the final user-selected default; PNG remains a selectable alternative. The 72-tile production benchmark measured 53,031 bytes for gzip CYBM, 53,373 for Zstandard CYBM and 124,424 for native PNG with exact hover identities. PNG's embedded identity grid accounts for most of its added bytes. The earlier 73,005-byte PNG prototype required indexed-pixel decoding and was not equivalent to browser-native decoding; its result is superseded. Seventy-two Chromium runs with a 1024 by 512 viewport found comparable visible latency at 1 Mbps/80 ms, zero-request cached revisits, and valid hover values throughout. Existing HTTP Zstandard support was verified; the final map route selects gzip for compatibility, with identity fallback, and prevents outer middleware from reapplying Zstandard. Standalone benchmark code stays in the Rust workspace; use development builds only.
